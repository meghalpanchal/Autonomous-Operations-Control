# Autonomous Operations Control

A real-time industrial equipment monitoring dashboard built with React, TypeScript and WebSockets.

The application simulates an operations control centre used to monitor autonomous equipment such as excavators, haul trucks and drills.

## Overview

Autonomous Operations Control demonstrates how a modern frontend application can consume continuous machine telemetry and transform it into useful operational information.

Live machine data is streamed from a Node.js WebSocket server every second and displayed through equipment status cards, fleet KPIs, telemetry charts and operational alerts.

## Features

- Real-time machine telemetry using WebSockets
- Automatic WebSocket reconnection
- Last-known-data handling during connection interruption
- Fleet-level KPI monitoring
- Machine health classification
- Running, idle, warning and critical states
- Live speed and temperature charts
- 30-second telemetry history
- Operational alert generation
- Search by machine name or ID
- Filter by machine health state
- Clickable alerts that navigate to affected equipment
- Responsive operations dashboard
- Empty, loading and disconnected states

## Architecture

Machine telemetry is generated by the Node.js simulation server and streamed to the React application using WebSockets.

The frontend encapsulates WebSocket lifecycle management inside a reusable custom React hook.

```text
Machine Simulator
       │
       ▼
Node.js WebSocket Server
       │
       │ telemetry every second
       ▼
useMachineWebSocket
       │
       ├── Connection state
       ├── Reconnect handling
       ├── Machine state
       └── Telemetry history
       │
       ▼
React Application
       │
       ├── Fleet Summary
       ├── Machine Selector
       ├── Health Monitoring
       ├── Telemetry Charts
       ├── Search & Filtering
       └── Operational Alerts
